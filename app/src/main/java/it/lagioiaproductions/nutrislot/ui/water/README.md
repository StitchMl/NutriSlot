# Water UI

- `route/`: aggancio navigation.
- `screen/`: composable principale del tracker acqua.
- `viewmodel/`: stato e mutazioni della feature.
- `state/`: modelli di stato UI.
- `components/`: sezioni visive principali.
- `dialogs/`: preset, amount dialogs e settings dialogs.
- `background/`: sfondi e layer decorativi.
- `theme/`: token cromatici e costanti visive.
