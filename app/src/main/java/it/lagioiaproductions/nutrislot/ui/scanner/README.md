# Scanner UI

- `api/`: client Gemini e parser della risposta.
- `route/`: schermata/entry point della feature.
- `viewmodel/`: orchestration della scansione.
- `state/`: stato UI e modelli di stato.
- `model/`: modelli di dominio UI-specifici.
- `components/`: hero cards, feedback cards e product cards.
- `media/`: supporto immagini e input fotografico.
- `support/`: assessment e logica ausiliaria non visuale.
